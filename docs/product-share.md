# 分享星匣

主标语：**你的 AI 记忆，始终属于你。**

“管理 → 设置 → 分享软件”是左侧导航中的独立标签页，“管理 → 分享软件”可以直接进入。左侧分类固定，右侧内容独立滚动。交互参考星笺的分享素材页，在星匣的原生 egui 阅读器中实现，不依赖浏览器或 Python 运行时。

- 文案：简短推荐、产品介绍，各有简体中文和英文版本。
- 图片：产品总览、换机与数据自主、为 AI 准备历史，各有中英文版本，共六张 1080 × 1440 PNG。
- 操作：选中正文手动复制、一键复制文案、复制项目链接、预览/放大图片、复制系统图片与保存 PNG。
- 切换语言保留文案类型与图片主题；分享操作不会保存其他设置草稿。

素材使用固定原创示意，不读取或截图用户聊天记录。复制成功以系统剪贴板接口返回成功为准；权限或系统服务错误会明确反馈。Linux 保留剪贴板对象以响应后续粘贴请求。复制图片会解码为系统 RGBA 图片，接收应用可能再次编码；保存 PNG 时保留内置原文件的精确字节。取消保存不写入文件，保存失败不显示成功。

## 表述范围

星匣汇聚现有本地来源与手动导入的数据；Claude Projects 的缓存可能不完整，ChatGPT 需要用户导入。换机迁移指复制完整档案目录与已经备份的文件，未复制或缺失的原文件需要先补齐。MCP、CLI 和 Skill 提供历史检索与原文阅读；使用方式由接入的 AI 客户端决定，不代表星匣内置模型、自动学习或自动把记忆导回其他产品。

本地优先不等于全部操作离线：可选择私有 GitHub 仓库同步文字和索引；打开项目链接会访问 GitHub。数据和备份没有由星匣加密。桌面安装包目前提供 Apple Silicon macOS 版，Python 后端的三平台 CI 不等于三平台桌面安装包或原生剪贴板已逐项验证。

## 再生成

素材目录与正文：`assets/share/catalog.json`。排版采用项目原生矢量图标、固定示例和系统字体，不截图真实主窗口。

```sh
swift tools/render_share.swift assets
python3 tools/prepare_share.py
```

Swift 使用 AppKit 输出原始 PNG；Pillow 仅用于制作时压缩为 256 色 PNG，同时更新字节数与 SHA-256，原图留在忽略的 `.local/share-poster-originals/`。正常构建与分享不依赖 Pillow。每次重制应检查全部修改过的图片排版和边缘，再运行 Rust 素材与交互测试。

图片通过固定 ID 与编译时字节对应，不把目录中的任意路径作为读取入口。运行时校验长度与解码尺寸。发布源包显式包含素材目录，图片直接嵌入桌面程序。

自动化验证涵盖全部 PNG 解码、素材配对、语言切换、保存字节与错误路径，不读取真实剪贴板。跨应用粘贴和 Windows/Linux 原生分享需要在对应系统核验。
